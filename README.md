# Онлайн-учебник: Data Engineering ETL

Интерактивный учебник по Data Engineering ETL: от основ ETL/ELT до Apache Airflow,
Apache Kafka, Apache Spark, качества данных и мониторинга - с практикой на реальных
кейсах.

## Что внутри

- **10 уроков** по темам курса:
  1. Введение в ETL/ELT
  2. Apache Airflow - часть 1
  3. Apache Airflow - часть 2
  4. Работа с источниками данных
  5. Apache Kafka
  6. Apache Spark - часть 1
  7. Apache Spark - часть 2
  8. Качество данных
  9. Мониторинг
  10. Итоговый проект «МегаЗвон» (зачёт)

- **Оригинальные диаграммы из презентаций** - схемы архитектуры Airflow, компонентов
  Kafka, репликации, Spark, Shuffle, стеков мониторинга и другие.

- **100 интерактивных вопросов** - по 10 на урок, 3 варианта ответа, мгновенная
  проверка с пояснением. Позиция правильного ответа перемешивается при каждой
  новой попытке.

- **Заготовки для практики** - DAG-файлы, docker-compose, данные и ноутбуки,
  которые скачиваются прямо из уроков.

- **Постепенное открытие контента** - урок становится доступен после зачёта
  предыдущего (не менее 7 правильных ответов из 10).

- **Трекинг прогресса** - сколько уроков пройдено, сколько заданий выполнено
  и сколько ещё осталось. Прогресс сохраняется в браузере ученика.
