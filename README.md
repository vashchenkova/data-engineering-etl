# Онлайн-учебник: Data Engineering ETL

Интерактивный учебник по Data Engineering ETL: от основ ETL/ELT до Airflow,
Kafka, Spark, качества данных и мониторинга - с практикой на реальных кейсах.

## Что внутри

- **10 уроков**:
  1. Введение в ETL/ELT
  2. Apache Airflow - часть 1 (+ практика 2)
  3. Apache Airflow - часть 2 (+ практика 3)
  4. Работа с источниками данных (+ практика 4)
  5. Apache Kafka (+ практика 5)
  6. Apache Spark - часть 1 (+ практика 6)
  7. Apache Spark - часть 2 (+ практика 7)
  8. Качество данных (+ практика 8)
  9. Мониторинг (+ практика 9)
  10. Итоговый проект «МегаЗвон» (зачёт)
- **22 авторские SVG-иллюстрации** к темам уроков (ETL, архитектура Airflow, DAG,
  Kafka-топики и репликация, Spark/Catalyst, Shuffle, метрики качества, стек мониторинга…).
- **100 интерактивных вопросов** (по 10 на урок, 3 варианта ответа, мгновенная проверка
  с пояснением).
- **Постепенное открытие контента**: урок N становится доступен после зачёта урока N-1
  (нужно ≥ 7 правильных ответов из 10).
- **Трекинг прогресса**: сколько уроков пройдено, сколько заданий выполнено и сколько
  осталось - сохраняется в браузере (localStorage), есть кнопка сброса.

## Как запустить локально

Сайт - чистая статика (HTML + CSS + JS), без сборки и зависимостей.

Вариант 1: открыть `index.html` двойным кликом.
Вариант 2 (рекомендуется): поднять локальный сервер -

```bash
cd vish-dwh-textbook
python -m http.server 8000
# затем открыть http://localhost:8000
```

## Как опубликовать в интернете (бесплатно)

Учебник полностью статический, поэтому подойдёт любой статический хостинг.

### GitHub Pages (рекомендуется)

1. Создайте публичный репозиторий, например `data-engineering-etl`.
2. Загрузите в него все файлы этой папки (`index.html`, `css/`, `js/`, `README.md`).
3. В репозитории: **Settings → Pages → Source: Deploy from a branch → main / root → Save**.
4. Через минуту учебник будет доступен по адресу
   `https://<ваш-логин>.github.io/data-engineering-etl/`.

Команды:

```bash
cd vish-dwh-textbook
git init && git add . && git commit -m "Онлайн-учебник Data Engineering ETL"
git branch -M main
git remote add origin https://github.com/<ваш-логин>/data-engineering-etl.git
git push -u origin main
```

### Альтернативы

- **Netlify** - перетащить папку в drag&drop-зону на netlify.com/drop.
- **Vercel** - `vercel` из папки проекта (framework: Other).
- **Cloudflare Pages** - подключить репозиторий или загрузить папку.
- Любой веб-сервер: просто скопировать папку в корень сайта.

## Прогресс студентов

Прогресс хранится в `localStorage` браузера каждого ученика (ключ
`de-etl-textbook-progress-v1`) - на сервер ничего не отправляется, учётные записи
не нужны. Ученик может сбросить прогресс кнопкой в подвале страницы.

## Как отредактировать контент

- Текст уроков, практика и вопросы - в `js/lessons1..3.js` (структура урока: `sections`,
  `practice`, `quiz`; у вопроса три поля: `q` - текст, `options` - 3 варианта,
  `correct` - индекс верного, `explain` - пояснение).
- Порог зачёта - `passScore` в `js/data.js`.
- Иллюстрации - SVG-строки в `js/app.js` (объект `ILLUS`).
